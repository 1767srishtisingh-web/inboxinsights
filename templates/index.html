The PDF report

Minimal by design. Zero clutter.

Traditional daily digests overwhelm you with paragraph summaries, AI fluff, and sender metadata. Inbox Insights focuses exclusively on what matters: the subject and the deadline.

  • Clean date heading & tally

    Clear date line with total emails received and deadlines detected.

  • One table with three columns

    Strictly #, Subject, and Deadline. No summary paragraphs or body text.

  • Actionable deadlines in raspberry

    Highlighted only when real action is required (submit, pay, confirm, attend).

  • Strictly today’s emails only

    Double-filtered by local midnight epoch and message timestamp. Never older mail.

  • Chronological order

    Rows ordered by arrival time (oldest first). Hindi and Devanagari supported.

Trust & data protection

Privacy by architecture

Your emails are confidential. Inbox Insights was built from day one to minimize data footprint.

01

Read-only access

We request strictly the gmail.readonly scope. We cannot send, draft, delete, or modify any emails or contacts.

02

Encrypted tokens

All Google OAuth refresh tokens are encrypted at rest using industry-standard Fernet symmetric encryption derived from your secret key.

03

Private signed links

PDF reports are served directly from this web server via secure, expiring 48-hour signed tokens. Never uploaded to anonymous file hosts.

04

Delete anytime

One-click account deletion permanently removes your profile, revoked tokens, and all generated PDF files from the server disk.
